# Wiztech Land Record

A mobile-friendly land measurement & deal calculator for the Gujarat land business — built by **Wiztech Innovation LLP**.

## Features

- **Unit Converter** — Acre, Guntha, Vigha (adjustable ratio), Sq Ft, Sq Meter, and 7/12 utara (Hectare-Are-Sq.M) conversion, with optional rate calculation and amount-in-words (Gujarati)
- **Deal Calculator** — Enter land in Acre+Guntha, price per Acre or per Guntha (auto-synced), get total amount payable with amount in Gujarati words
- **History** — Save deal calculations for the session
- **PDF Export** — Save any calculation as a PDF via browser print
- **WhatsApp Share** — Share deal summary directly to WhatsApp
- **Banakhat Draft** — Generate a simple sale-agreement draft text (for reference only — always get it checked by a lawyer before registration)

## How to use

Just open `index.html` in any browser (Chrome, Safari, etc). No installation, no server, no dependencies — everything runs in the browser.

### Host it for free with GitHub Pages

1. Go to this repository's **Settings → Pages**
2. Under **Source**, select the `main` branch and `/ (root)` folder
3. Save — your live link will appear as `https://<your-username>.github.io/<repo-name>/`
