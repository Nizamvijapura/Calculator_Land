# Smart Land Calculator

**Developed by Wiztech Innovation LLP**

Smart Land Calculator એ જમીનના માપનું રૂપાંતર અને ગુંઠા મુજબ રકમની ગણતરી કરવા
માટે બનાવેલ સરળ વેબ આધારિત કેલ્ક્યુલેટર છે.

## મુખ્ય સુવિધાઓ

-   Acre, Guntha, Sq Ft અને Vigha વચ્ચે જમીનના માપનું રૂપાંતર.
-   7/12 ઉતારામાંથી હેક્ટર, આર અને ચોરસ મીટર મુજબ માપ દાખલ કરવાની સુવિધા.
-   ગુંઠા મુજબ ભાવ અને કુલ રકમની ગણતરી.
-   Converter માં PDF રિપોર્ટ સેવ કરવાની સુવિધા.
-   Excel-style Guntha / Rate Calculator.
-   એકથી વધુ Rows ઉમેરવાની અને Rows દૂર કરવાની સુવિધા.
-   Guntha અને Total Amount દાખલ કરતાં પ્રતિ ગુંઠાનો Rate આપમેળે ગણાય છે.
-   Settings માં Acre અને Vigha માટે Guntha નું પ્રમાણ સેટ અને સેવ કરી શકાય છે.
-   Mobile અને Desktop બંનેમાં ઉપયોગ કરી શકાય તેવી ડિઝાઇન.

## GitHub પર અપલોડ કરવાની રીત

1.  GitHub પર તમારું Repository ખોલો.
2.  `Add file` → `Upload files` પસંદ કરો.
3.  નીચેની ફાઇલો Repository માં અપલોડ કરો:
    -   `index.html` --- Smart Land Calculator ની મુખ્ય HTML ફાઇલ.
    -   `README.md` --- આ માર્ગદર્શિકા.
4.  `Commit changes` પર ક્લિક કરો.

> મુખ્ય HTML ફાઇલનું નામ `index.html` જ રાખો, જેથી GitHub Pages તેને હોમપેજ તરીકે
> ખોલી શકે.

## GitHub Pages ચાલુ કરવાની રીત

1.  Repository માં `Settings` ખોલો.
2.  ડાબી બાજુ `Pages` પસંદ કરો.
3.  `Build and deployment` વિભાગમાં `Deploy from a branch` પસંદ કરો.
4.  Branch તરીકે `main` અને Folder તરીકે `/ (root)` પસંદ કરો.
5.  `Save` પર ક્લિક કરો.
6.  થોડા સમય પછી GitHub Pages દ્વારા આપેલી Website Link ખોલો.

## અપડેટ કેવી રીતે કરવું?

1.  નવી HTML ફાઇલનું નામ `index.html` રાખો.
2.  Repository માં જૂની `index.html` ને નવી ફાઇલથી Replace કરો.
3.  `Commit changes` કરો.
4.  Website ખોલીને `Ctrl + F5` દબાવી Hard Refresh કરો.
